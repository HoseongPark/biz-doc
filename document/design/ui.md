# 04. 화면 구성 (UI)

> 상태: 합의됨 — Pencil 목업(`document/design/page.pen`)으로 검증 완료

## 영역별 상세

### 상단 바
- 로고(biz-doc studio) · 워크스페이스 경로 pill · 새로고침 버튼 · **컨텍스트 추가**(주 액션, accent 버튼)

### Context Map (중앙, 메인 뷰)
- 컨텍스트 = 그룹 박스(accent 테두리, 제목 옆에 파일명 배지 `swing-session.yml`)
- **컨텍스트 박스는 두 구역으로 완전 분리**:
  - **모델 구역(상단)**: "모델" 라벨 + Root Aggregate/Entity/Value/Stereotype 카드들 (자유 배치)
  - **서비스 구역(하단 밴드)**: 전체 폭 가로 구분선 아래, 연한 청록(`$type-service` ~5% 알파) 배경 밴드 + "서비스" 라벨 + Service 카드들
- 도메인 = 박스 안의 카드. 카드 구성:
  - **테두리**: 유형 색상 — Root Aggregate(파랑) / Entity(초록) / Value(보라) / Stereotype(주황) / Service(청록). 선택 시 두껍게(1.5px)
  - **유형 헤더 밴드**: 카드 최상단에 유형 소프트 색상 배경 + 유형 아이콘 + 유형 이름을 유형 색상의 굵은 글씨로 표시 (위쪽 모서리만 라운드). 아이콘은 사이드바 트리와 동일 체계(database/component/diamond/list/workflow)
  - **Root Aggregate 강조**: 헤더 밴드를 소프트가 아닌 솔리드 accent + 흰색 텍스트로 — 컨텍스트의 중심임을 표시
  - 제목(한글 이름, `meta.name`) + 부제(영문 도메인 키, 모노스페이스)
  - 속성 목록: 영문 이름(모노스페이스) + 한글 설명(아래 줄) + 타입 칩(연회색 배경 배지, 우측 정렬)
  - **비즈니스 로직 섹션**: `$bg` 배경으로 속성 목록과 구분. 로직 이름(모노스페이스) + 설명
  - **Stereotype 카드**: 속성/룰 대신 열거 값(values) 목록 표시 — 유형 색상 도트 + 상수 이름(영문 대문자, 모노스페이스) + 한글 설명
  - **Service 카드**: 속성 대신 오퍼레이션(operations) 목록 — 오퍼레이션 이름(모노스페이스) + 설명 + 관련 도메인 칩(`related-domains`)
- 코드 성격 텍스트(도메인 키·속성명·타입·로직명·열거 상수)는 모노스페이스(JetBrains Mono)로 통일, 한글 설명과 시각적으로 구분
- 관계 = 카드 간 화살표 + 관계명 레이블(예: `포함됨`)
- 노드 드래그로 배치 → `.config/layout.json`에 좌표 저장
- 노드 핸들을 드래그해 다른 노드에 연결 → 관계 생성 다이얼로그
- 좌하단 줌 컨트롤 (− / 100% / +)
- 선택된 카드는 accent 테두리로 강조

### 사이드바 (좌, 240px)
- 컨텍스트 → 도메인 트리, 도메인 아이콘은 유형별 색상
- 컨텍스트 아래 도메인은 **"모델" / "서비스" 그룹 캡션**으로 나눠 표시 (캔버스 구역 분리와 일치)
- 항목 클릭 시 해당 노드로 포커스 이동, 선택 항목은 accent-soft 하이라이트

### 상세 패널 (우, 300px, 선택 시 열림)
- **도메인 선택**: 유형 배지 · 이름 · 설명 → 속성 편집 → 비즈니스 로직 편집(name/description + 로직 추가) → 관계 목록(관계명 → 대상, + 관계 추가) → **이력(audit) 섹션은 패널 최하단**(작성자/생성/수정, 읽기 전용) → 삭제 버튼(danger)
  - `identity.id`(UUID)는 패널에 표시하지 않음 (앱 자동 관리 값)
  - **속성 편집은 속성 1개 = 카드 1장(묶음)**: 상단 한 줄에 속성명(모노스페이스)과 편집 아이콘, 가장 오른쪽에 타입 드롭다운 칩 — 속성명과 타입이 같은 레벨. 그 아래 줄에 한글 설명
- **엣지(관계) 선택**: 관계명 수정 / 삭제
- **컨텍스트 선택**: 컨텍스트 이름 수정 / 삭제

### 빈 상태
- 워크스페이스 미선택 시 "폴더 열기" 화면 + 최근 워크스페이스 목록
