# 04. 화면 구성 (UI)

> 상태: 합의됨 — Pencil 목업(`document/design/page.pen`)으로 검증 완료

## 레이아웃

```
┌────────────────────────────────────────────────────┐
│ 상단 바: 로고 · 워크스페이스 경로 · 새로고침 · 컨텍스트 추가 │
├──────────┬─────────────────────────┬───────────────┤
│ 사이드바  │      Context Map        │  상세 패널     │
│ (240px)  │      (React Flow)       │  (300px)      │
│          │                         │               │
│ 컨텍스트  │  ┌─ 스윙 레코더 ──────┐  │  유형 배지     │
│ /도메인   │  │ [스윙 세션]        │  │  이름/설명     │

└──────────┴─────────────────────────┴───────────────┘
```

## 영역별 상세

### 상단 바
- 로고(biz-doc studio) · 워크스페이스 경로 pill · 새로고침 버튼 · **컨텍스트 추가**(주 액션, accent 버튼)

### Context Map (중앙, 메인 뷰)
- 컨텍스트 = 그룹 박스(accent 테두리, 제목 옆에 파일명 배지 `swing-session.yml`)
- 도메인 = 박스 안의 카드. 카드 구성:
  - **테두리**: 유형 색상 — Root Aggregate(파랑) / Entity(초록) / Value(보라) / Stereotype(주황). 선택 시 두껍게(1.5px)
  - **유형 헤더 밴드**: 카드 최상단에 유형 소프트 색상 배경 + 유형 이름을 유형 색상의 굵은 글씨로 표시 (위쪽 모서리만 라운드)
  - 제목(한글 이름, `meta.name`) + 부제(영문 도메인 키)
  - 속성 목록: 영문 이름 + 한글 설명 + 타입
  - **비즈니스 로직 섹션**: 로직 이름 + 설명
  - **Stereotype 카드**: 속성/룰 대신 열거 값(values) 목록 표시 — 상수 이름(영문 대문자) + 한글 설명
- 관계 = 카드 간 화살표 + 관계명 레이블(예: `포함됨`)
- 노드 드래그로 배치 → `.config/layout.json`에 좌표 저장
- 노드 핸들을 드래그해 다른 노드에 연결 → 관계 생성 다이얼로그
- 좌하단 줌 컨트롤 (− / 100% / +)
- 선택된 카드는 accent 테두리로 강조

### 사이드바 (좌, 240px)
- 컨텍스트 → 도메인 트리, 도메인 아이콘은 유형별 색상
- 항목 클릭 시 해당 노드로 포커스 이동, 선택 항목은 accent-soft 하이라이트

### 상세 패널 (우, 300px, 선택 시 열림)
- **도메인 선택**: 유형 배지 · 이름 · 설명 → meta(id, audit 읽기 전용) → 속성 편집(name/type/description 3필드 + 속성 추가) → 비즈니스 로직 편집(name/description + 로직 추가) → 관계 목록(관계명 → 대상, + 관계 추가) → 하단 삭제 버튼(danger)
- **엣지(관계) 선택**: 관계명 수정 / 삭제
- **컨텍스트 선택**: 컨텍스트 이름 수정 / 삭제

### 빈 상태
- 워크스페이스 미선택 시 "폴더 열기" 화면 + 최근 워크스페이스 목록
